# Before any paper or public release

- Full-text prior-art review, accurate bibliography and a scoped novelty statement.
- Real-model evidence, independent rerun, uncertainty, complete ablations and negative results.
- Clear train/dev/calibration/test separation, contamination audit and all tuning disclosed.
- Dataset/model/code/output rights reviewed independently; no confidential data or secrets.
- Reproducible tables/figures with run links and exact model revisions.
- Owner approval for public repository visibility, license, artifact release and submission.

None of these gates is implied by creating this lab scaffold.
