# Contributing

Every contribution must be traceable to a source, issue/idea, or experiment. Use small branches and preserve provenance. A model card needs primary sources, access/license status, unknowns, review depth and execution status. A result needs a frozen protocol, model and data revisions, reproducible run manifest and limitations.

Run tests and local validation before commit. Do not add heavyweight runtime dependencies to the offline core. Live integrations belong in optional modules and must fail closed when credentials or permissions are absent.

Use experiment IDs E001 onward and idea IDs H001 onward. Record meaningful design decisions under research/decisions. Do not present templates as filled records or planned experiments as completed evidence.
