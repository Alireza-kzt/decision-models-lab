# ایدهٔ H008 — policy و value برای جست‌وجوی مقید

وضعیت: **فرضیه / اجرا نشده / novelty تأیید نشده**. هیچ‌یک هدف نهایی پروژه نیست.

## سؤال
آیا امتیازدهی candidate action و ارزش state، در جست‌وجوی مقید بهتر از heuristicهای ساده عمل می‌کند؟

## فرضیهٔ ابطال‌پذیر
یک representation ساختاری با policy/value شاید تعداد nodeهای جست‌وجو را در کیفیت خروجی ثابت کاهش دهد.

## نزدیک‌ترین پیشینه و ریسک تکراری بودن
این شاخه اختیاری و مرتبط با علاقهٔ تولید پلان است؛ افزودن policy/value به‌تنهایی نوآوری نیست. مرور کامل neural combinatorial optimization و learned search هنوز لازم است.

## کوچک‌ترین آزمایش مفید
ابتدا puzzle/مسئلهٔ مقید کوچک با oracle و optimum معلوم؛ greedy، beam، heuristic solver، policy-only و policy+value با بودجهٔ node برابر. سپس انتقال به یک دامنهٔ واقعی دارای validator مستقل.

## معیار و کنترل
feasibility، optimality gap در نمونه‌های قابل حل دقیق، node expansions، runtime کل و generalization اندازه/قید.

## چه نتیجه‌ای ما را منصرف می‌کند؟
کل بهبود از solver یا افزایش budget بیاید؛ feasibility به علت validator ناقص بالا دیده شود؛ یا برتری فقط بر نمونه‌های تمرینی باشد.

## وابستگی قبل از اجرا
انتخاب dataset با مجوز روشن، pin کردن checkpoint، نوشتن adapter و preregistration. هیچ GPU یا مبلغی در این ایده تصویب نشده است. بعد از pilot، effect size عملی و سقف trialها مشخص شود؛ test برای انتخاب آن‌ها استفاده نشود.

## شواهد و کار باز
مرور پیشینهٔ اختصاصی هنوز انجام نشده است؛ این ایده صرفاً یک مسیر پیشنهادی است.

**شواهد محلی:** ندارد. **تصمیم:** باز. نتیجهٔ منفی نیز باید همراه با علت حفظ شود.
