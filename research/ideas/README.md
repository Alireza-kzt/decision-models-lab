## انتخاب میان ایده‌ها
به هر ایده برای مشاهدهٔ واقعی شکست، تازگی محتمل، قابلیت ابطال، baseline قوی، دسترسی داده، هزینه، علاقهٔ شخصی و ریسک انتشار امتیاز بدهید. امتیازها اکنون خالی‌اند؛ نمره‌سازی بدون شواهد انجام نشده است.

## قانون توقف
اگر ایده را با baseline ساده نمی‌توان مقایسه کرد یا شکست آن را نمی‌توان تعریف کرد، آن را به آزمایش بزرگ ارتقا ندهید. نتیجهٔ منفی دلیل حذف یادداشت نیست.
