# آزمایشگاه مدل‌های تصمیم‌گیری 🔬

این مخزن برای **مطالعه، دست‌کاری مدل، آزمایش و کشف سؤال پژوهشی** ساخته شده است. هنوز موضوع نهایی، مدل پایه و ادعای مقاله انتخاب نشده‌اند. پروژهٔ تولید پلان فقط یک مسیر اختیاری است و دامنهٔ آزمایشگاه را محدود نمی‌کند.

## از کجا شروع کنم؟
ابتدا [شروع مطالعه](docs/START_HERE.fa.md)، سپس [فهرست مدل‌ها](catalog/README.md)، [آموزش مفهومی](docs/02_concepts.fa.md)، [مطالعهٔ معماری](docs/03_architectures.fa.md) و [بانک ایده‌ها](research/ideas/README.md) را بخوانید. [نقشهٔ پژوهش](docs/09_roadmap.fa.md) ترتیب تصمیم‌های بعدی را مشخص می‌کند.

## این مخزن چگونه به مقاله منتهی می‌شود؟
مشاهدهٔ مستند ← سؤال دقیق ← فرضیهٔ ابطال‌پذیر ← آزمایش کوچک ← تحلیل خطا ← کنترل و ablation ← نتیجهٔ بازتولیدپذیر ← ادعای محدود و قابل دفاع.

تعویض backbone یا fine-tune معمولی به‌تنهایی دلیل نوآوری نیست. نتیجهٔ منفی هم ارزش دارد، به شرط آنکه پروتکل و محدودیت‌ها ثبت شوند.

## وضعیت فعلی
کارت مدل‌ها، پیوند مقاله‌ها، قالب ثبت مطالعه، ایده‌ها و پروتکل‌ها آماده‌اند. زیرساخت آفلاین ارزیابی نیز وجود دارد. **هیچ مدل واقعی این فهرست اجرا نشده، هیچ هزینهٔ API/GPU ایجاد نشده و مقایسهٔ علمی تکمیل نشده است.** جزئیات در [وضعیت](STATUS.md).

## استفادهٔ روزمره
برای یک ایده از [قالب ایده](templates/idea.md) استفاده کنید. پیش از اجرای آزمایش، [قالب آزمایش](templates/experiment.md) را پر کنید؛ پس از اجرا، گزارش را با manifest و شناسهٔ commit پیوند دهید. دستورهای اجرایی در [راهنمای اجرا](docs/05_getting_started.fa.md) آمده‌اند.

دادهٔ واقعی، API key، checkpoint و گزارش شامل اطلاعات محرمانه را commit نکنید. خصوصی بودن ریپو جای مجوز استفاده از داده یا مدل را نمی‌گیرد.
