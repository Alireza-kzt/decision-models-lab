# نقشهٔ پژوهش بدون تعهد به نتیجه

این مراحل gate دارند، نه مهلت یا وعدهٔ زمان‌بندی.

| مرحله | خروجی لازم برای عبور | دلیل توقف/بازنگری |
|---|---|---|
| مطالعهٔ هدفمند | دو کارت مدل با code audit و دو پیپر با full-text review | جزئیات اجرا یا مجوز روشن نیست |
| baseline ساده | classifier ارزان، مدل باز کوچک و یک مقایسه‌گر مناسب | داده و معیار هنوز تعریف نشده |
| failure map | حداقل یک شکست تکرارپذیر با گروه‌بندی درست | شکست ناشی از bug یا قالب ورودی است |
| انتخاب فرضیه | آزمایش کوچک، کنترل و معیار ابطال مشخص | ایده فقط تکرار upstream است |
| اصلاح مدل | baseline ثابت + یک تغییر اصلی | چند تغییر هم‌زمان علت را مبهم می‌کند |
| ablation و transfer | چند seed، حوزهٔ تازه، تحلیل خطا و هزینه | فقط یک task یا seed بهتر است |
| ارزیابی تأییدی | holdout دست‌نخورده و دستور بازتولید | test در تصمیم‌سازی استفاده شده |
| نگارش | claim-to-evidence map و محدودیت‌ها | نتایج کافی نیست یا novelty تأیید نشده |

## پیشنهاد شروع، نه انتخاب نهایی
از یک مدل encoder کوچک و یک implementation شفاف head آغاز کنید؛ هدف، فهمیدن تفاوت مکانیزم‌هاست. مدل 27B را صرفاً به‌دلیل leaderboard انتخاب نکنید. مقایسه با classifier آموزش‌دیده و یک baseline مولد محدودشده را حذف نکنید؛ انگیزه در [P003](../catalog/papers/P003.md) آمده است.

## پیش از هزینه
بودجهٔ کل، حد توقف، تعداد run، حجم دادهٔ بیرون‌فرستاده‌شده و نگهداری artifacts معلوم باشد. در تحویل اولیه هیچ بودجهٔ GPU/API فرض یا خرج نشده است.
