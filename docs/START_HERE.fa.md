# شروع مطالعه

## امروز لازم نیست هدف نهایی را بدانید
هدف این مرحله کشف مسئله است، نه دفاع از یک راه‌حل از پیش انتخاب‌شده. از میان کارت‌ها دو implementation باز با اندازه‌های متفاوت و یک baseline ساده انتخاب کنید؛ انتخاب نهایی پس از بررسی مجوز، امکان اجرا و سؤال پژوهشی انجام شود.

## مسیر خواندن
۱. [منشور](01_charter.fa.md): چه چیزی در دامنه است و چه چیزی تعهد نشده است؟
۲. [مفاهیم](02_concepts.fa.md): تصمیم، احتمال، type safety و calibration چه تفاوتی دارند؟
۳. [معماری‌ها](03_architectures.fa.md): کدام اجزا واقعاً قابل تغییرند؟
۴. [فهرست](../catalog/README.md): منبع هر مدل و سطح بررسی چیست؟
۵. [ممیزی ادعاها](04_evidence_audit.fa.md): کدام گفته‌های قبلی باید دقیق‌تر شوند؟
۶. [بانک ایده](../research/ideas/README.md): چه آزمایشی می‌تواند ایده را رد کند؟
۷. [روش آزمایش](06_evaluation.fa.md): چگونه مقایسهٔ منصفانه بسازیم؟

## نخستین خروجی مطلوب
یک برگهٔ یک‌صفحه‌ای بنویسید: «در شرایط X، مدل Y شکست Z دارد؛ تغییر M شاید metric Q را بهتر کند؛ کنترل C نشان می‌دهد بهبود صرفاً از داده/بودجه/اندازه نیست.» اگر X یا Z معلوم نیست، هنوز زمان ساخت معماری بزرگ نیست.

## تعریف پیشرفت
پیشرفت یعنی کاهش عدم‌قطعیت: یک منبع خوانده‌شده، یک خطای تأییدشده، یک فرضیهٔ ردشده یا یک run قابل بازتولید. تعداد فایل یا تعداد ایده معادل پیشرفت تجربی نیست.
