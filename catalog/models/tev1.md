## آنچه منبع می‌گوید
README استفاده از Qwen3.5-4B، LoRA و همان language-model output head را تصریح می‌کند. خروجی یک حرف گزینه است و مثال inference پاسخ را محدود می‌کند؛ logprob معادل احتمال کالیبره‌شده نیست.

## احتیاط و سؤال پژوهشی
این مدل baseline مولدِ محدودشده است، نه شواهد یک head غیرمولد. نتایج ذخیره‌شدهٔ upstream روی development تکرارشده‌اند؛ نسخهٔ job و هویت فایل‌های آموزش نیز طبق README نیاز به بررسی دارند.
