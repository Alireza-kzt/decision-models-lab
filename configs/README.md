# Configurations

`smoke.json` defines the deterministic, cost-free uniform-baseline demonstration. It is not a model-training config. Research plans are under experiments/plans and intentionally contain unresolved fields.

When adding real integrations, pin dependencies and model/tokenizer/data revisions in an integration-specific environment. Do not place API keys or private payloads here. Never use a generic provider URL or guessed API contract without a primary-source check.
